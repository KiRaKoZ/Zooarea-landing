# ZooArea Landing — გაერთიანებული ვერსია

ეს არის **ძველ `zooarea-landing(1).zip` პროექტზე დაფუძნებული** განახლება. შენარჩუნებულია მთავარი კომპოზიცია, გამართული ერთეკრანიანი განლაგება, ქარ/EN/RU და მობილური ოთხი ტაბი. მეორე ZIP-იდან დამატებულია 11 რეალური კატეგორიის ფოტო, 19 გადამოწმებადი მისამართი (დამატებით ორი ფილიალი დაუზუსტებელი მისამართით), ფილიალების ფოტოებიანი შიდა-სქროლი, ძებნა და ფოტოგალერეა. ფილიალების ფოტოგალერეები დამატებულია: 16 ფილიალი / 46 ფოტო (ძირითადი და დამატებითი).

## გაშვება

გახსენით `index.html` თანამედროვე ბრაუზერში. თუ ლოკალური ფაილების შეზღუდვა შეგხვდათ, პროექტის საქაღალდიდან გაუშვით `python3 -m http.server 8000` და გახსენით `http://localhost:8000`.

## ძირითადი ფაილები

- `index.html` — HTML კონსტრუქცია, სემანტიკა და მოდალური ფანჯრები.
- `assets/scss/global.scss` — ყველა ფერი, ფონტი, გარე განლაგება და მედია-ქუერი ერთ ადგილას.
- `assets/css/global.css` — იგივე CSS, რაც უშუალოდ იტვირთება ბრაუზერში (SCSS plain CSS-compatible).
- `assets/js/data.js` — ფილიალების მისამართები, ტელეფონები, კატეგორიები და გარე ბმულები.
- `assets/js/app.js` — ფილტრაცია, ენები, კატეგორიების სქროლი და გალერეა.
- `assets/js/branch-photos.js` — ფოტოებისთვის გენერირებული სია.
- `tools/prepare_photos.py` — ატვირთული ფილიალის ფოტოების მომზადება და ოპტიმიზაცია.
- `assets/brand/` და `assets/categories/` — მოწოდებული ფაილების WebP-ოპტიმიზებული ასლები.

## ფილიალების ფოტოების დამატება

ფილიალებისთვის უკვე არსებობს საქაღალდეები `assets/branches/<branch-id>/input/`. მაგალითად, ავჭალისთვის: `assets/branches/avchala/input/`.

1. ჩააგდეთ მთავარი ფოტო `cover.jpg` სახელით და დანარჩენები `02.jpg`, `03.jpg` და ა.შ.
2. Terminal-ში, პროექტის საქაღალდიდან, ერთხელ: `python3 -m pip install Pillow`
3. ყოველ ფოტოების განახლებაზე: `python3 tools/prepare_photos.py`
4. განაახლეთ ბრაუზერის გვერდი. პირველი ფოტო გამოჩნდება სიაში, დანარჩენები გაიხსნება დეტალურ გალერეაში (თითებით / ისრებით).

ფოტოები გადაყვანილია WebP-ში `quality=90, method=2`, 1600 პიქსელამდე თითოეულ განზომილებაში, EXIF ორიენტაციის გათვალისწინებით. `input/` ორიგინალები უცვლელი რჩება.

## ცვლილება ფერებში და ფონტებში

შეცვალეთ `assets/scss/global.scss` ფაილში `:root` ცვლადები (`--green`, `--orange-deep`, `--font` და სხვ.). შემდეგ CSS-ის გასაახლებლად:

```bash
cp assets/scss/global.scss assets/css/global.css
```

ფონტი: `Noto Sans Georgian` + `Manrope`, ინტერნეტის გარეშე — სისტემური შემცვლელი ფონტი.

## შესამოწმებელი პუნქტები გამოქვეყნებამდე

- მისამართები აღებულია მოწოდებული ZooArea-ს PDF ცხრილიდან. ერთი ჩანაწერი — გიორგი ჩიტაიას ქუჩა 39ა — წყაროში **Not published** სტატუსითაა; ფილიალების სიაში შენარჩუნებულია, მაგრამ გამოტანილია შესაბამისი გაფრთხილება დეტალურ ფანჯარაში.
- რუკის ბმულები ღია Google Maps ძიების ბმულებია და არა კონკრეტული Place ID.
- Wolt/Glovo ღილაკები მიჰყავს ZooArea-ს გვერდებზე. ოფიციალური ლოგოების გამოსახულებები დისტანციური წყაროებიდან იტვირთება, ამიტომ მათ სჭირდებათ ინტერნეტი; გათვალისწინებულია ტექსტური სათადარიგო ვარიანტი.
- ატვირთული რეალური ფოტოები უკვე ინტეგრირებულია 16 ფილიალში. დანარჩენ ფილიალებს ნაჩვენები აქვს სათადარიგო SVG ნახატი.
- სოციალური ქსელები, ტელეფონი და ყველა კატეგორია შეიძლება შეიცვალოს `data.js`-ში.
- ძირითადი გვერდი არ ისქროლება; ფილიალები, კატეგორიები, მობილური პანელები და მოდალური ფოტოგალერეა სქროლდება ცალ-ცალკე.

## v3 — რუკა, აიქონები, preloader, lazy-loading, ანიმაციები

ამ გამოშვებაში ყველა არსებული ფოტო და მისამართი შენარჩუნებულია: **21 ფილიალის ჩანაწერი**, **16 ფილიალის 46 რეალური ფოტო**, **11 კატეგორიის ფოტო**, ქარ/EN/RU ენები და მობილურის ნავიგაცია.

### Google Maps

- დესკტოპზე „ჩვენი ფილიალები“ ბლოკის სათაურთან არის **„რუკა“** ღილაკი. მისი დაჭერა ხსნის ფილიალის დეტალურ ფანჯარას გაშლილი რუკით.
- ყველა ფილიალის დეტალურ ფანჯარაში, **თუ მისამართი ცნობილია**, არის „რუკის ჩვენება“ და „Google Maps“ ღილაკები. რუკის iframe ჩნდება და ქსელიდან იტვირთება მხოლოდ ღილაკზე დაჭერის შემდეგ (lazy on demand).
- „Google Maps“ ბმული ოფიციალური Google Maps URL-ით ხსნის მისამართის ძებნას ახალ ფანჯარაში ან შესაბამის აპში. **ეს არის საძიებო ბმული, არა დადასტურებული Place ID / ზუსტი GPS წერტილი.**
- iframe-ისთვის სტანდარტული, დოკუმენტირებული Google Maps Embed API მოითხოვს API გასაღებს. საიტში ამჟამად დამატებულია **გასაღების გარეშე თავსებადობის ვარიანტი** (`maps.google.com/maps?q=...&output=embed`), რომელიც შესაძლოა მომავალში ან გარკვეულ გარემოში არ იმუშაოს. ყოველთვის ხელმისაწვდომია Google Maps-ის გარე ბმული.
- თუ გსურთ ოფიციალურად მხარდაჭერილი API-ით მუშაობა, Google Cloud-ში შექმენით, დომენზე შეზღუდეთ და ჩართეთ Maps Embed API key; შემდეგ `assets/js/data.js`-ში შეავსეთ `googleMapsEmbedKey`. **API გასაღები არასდროს ჩაწეროთ შეუზღუდავად.**
- ნუცუბიძისა და ზაჰესის მისამართები ჯერ მითითებული არ არის, ამიტომ მათთან რუკის ღილაკი დამალულია.

### აიქონები და კონტაქტი

- სოციალური ქსელების (Facebook / Instagram / TikTok) SVG აიქონები ლოკალურია: `assets/icons/`. გარედან მათი ჩატვირთვა არ არის საჭირო.
- დამატებულია ტელეფონის, რუკის, ძებნის, დროისა და მობილური ნავიგაციის SVG ხატულები.
- Wolt / Glovo-ს ღილაკებისთვის დამატებულია ლოკალური ბრენდული წარწერის SVG ვარიანტები (სტილიზებული ვექტორული ნიშნები), რათა ქსელის შეცდომის დროსაც ჩანდეს.
- კონტაქტების ბლოკში მოცემულია ტელეფონი, Google Maps-ის ძებნა, Wolt, Glovo და სამი სოციალური ქსელი, სამუშაო საათები.
- სოციალურ ბმულებს და ტელეფონს შეცვლით `assets/js/data.js`-ში.

### ფოტოების ჩატვირთვა

- კრიტიკულად მნიშვნელოვანი ლოგო და მთავარი ძაღლის ფოტო წინასწარ იტვირთება HTML `rel="preload"`-ით.
- preloader უჩინარდება მთავარი ძაღლის ფოტოს გაშიფვრის (`decode`) შემდეგ ან მაქსიმუმ ~1.6 წმ-ზე, რათა გვერდი არ ჩაიკეტოს.
- ფილიალების პატარა ფოტოები და კატეგორიები იტვირთება **IntersectionObserver**-ით მაშინ, როცა ეკრანს უახლოვდება. მობილური კატეგორიების პირველი ექვსი ფოტო დაუყოვნებლივ იტვირთება პანელის გახსნისას.
- ფოტოგალერეის დიდი სურათები იტვირთება მხოლოდ ფილიალის გახსნის შემდეგ; Google Maps iframe — მხოლოდ მოთხოვნის შემდეგ.
- ფოტოები შენარჩუნებულია WebP ფორმატში; ხელახლა დამატებისთვის კვლავ მუშაობს `python3 tools/prepare_photos.py`.

### ცოცხალი ანიმაციები

- პატარა SVG ძაღლი მოძრაობს ეკრანის ქვედა ნაწილში, მარცხნიდან მარჯვნივ, დაახლოებით 57–76 წამიანი უსასრულო ციკლით (მობილურზეც).
- ფეხები და კუდი მოძრაობს CSS keyframes-ით; ძაღლი `pointer-events: none` რეჟიმშია და არც ერთ ღილაკს არ ფარავს.
- კატეგორიების ფოტოები, ფილიალის ბარათები, სოციალური ღილაკები და ბანერი მიიღეს რბილი hover/transition ეფექტები.
- `prefers-reduced-motion: reduce` სისტემური პარამეტრი ამცირებს ან გამორთავს მოძრაობას.

### სკრიპტები და სტილები

- `index.html` — სექციები, სამი modal ფანჯარა, SVG ძაღლი და preloader.
- `assets/js/app.js` — ფუნქციონალი, სამენოვანი ტექსტები, რუკის გახსნა, გალერეა, lazy-loading და preloader-ის დახურვა.

- `assets/icons/` — ყველა ლოკალური SVG.
