# ფილიალების რეალური ფოტოები

თითოეულ ფილიალს აქვს საკუთარი საქაღალდე (მაგ., `avchala`, `chovelidze`).

1. ფოტოები განათავსეთ შესაბამის `input/` საქაღალდეში (JPG, PNG, WebP).
2. მთავარი ფოტოს ფაილს დაარქვით `cover.jpg` ან `main.jpg` (ასევე მუშაობს `01.jpg`).
3. დამატებითი ფოტოების სახელები შეიძლება იყოს `02.jpg`, `03.jpg` და ა.შ.
4. პროექტის ძირიდან გაუშვით `python3 -m pip install Pillow` და შემდეგ `python3 tools/prepare_photos.py`.

სკრიპტი ორიგინალებს არ შლის: ქმნის ხარისხიან, 1600px-მდე WebP ფოტოებს და განაახლებს `assets/js/branch-photos.js` ფაილს. მთავარი ფოტო ავტომატურად გამოჩნდება ფილიალების სიაში; ყველა სურათი — დეტალურ გალერეაში.

ნუ წაშლით ან შეცვლით `input/` საქაღალდეებს. 16 ფილიალის 46 ფოტო უკვე დამატებულია. დანარჩენი ფილიალების ფოტოები ჯერ არ არის მოწოდებული.

გაითვალისწინეთ: ვებსაიტში ოპტიმიზებული WebP ფოტოები უკვე დევს, ხოლო უცვლელი JPEG ორიგინალები ცალკე ZIP-შია. სრული ფოტოკოლექციის თავიდან მოსამზადებლად გადაიტანეთ შესაბამისი ორიგინალები `input/`-ში.

ფოტოების მომზადების სკრიპტი უკვე არსებულ WebP გალერეებს ინარჩუნებს, თუ კონკრეტული ფილიალის `input/` ცარიელია.
